## Rule Format

### Short descriptive title

**Situation:** When this type of situation occurs.

**Preferred behavior:** What should normally be done.

**Reason:** Why this behavior is preferred. When useful, note whether it came from explicit direction or repeated corrections.

**Confidence:** Low / Medium / High.

## Maintenance

- Record only evidence from this manager's feedback or explicit instructions; do not import generic preferences.
- Replace `None recorded.` when adding the first rule to a section.
- Move rather than duplicate a candidate when promoting it.
- Merge overlapping rules and keep wording narrow enough to avoid unintended situations.
- If rules conflict, prefer the more specific rule; if conflict remains material, follow the skill priority order and seek a manager decision only when the underlying choice qualifies as C.
- Remove or revise a rule when the manager explicitly retracts or supersedes it.
