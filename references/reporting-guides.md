# Reporting & Escalation Guides

Supplementary phrasing and pre-report checks for the stable rules in `SKILL.md`. Load when composing a B request, a manager-facing report, or before stopping to escalate.

## B — High-Leverage Help Phrasing

Reference phrasing, not a mandatory template. Prefer natural prose; use this only when it fits.

«I can continue with the current approach.
If you can provide X, it would significantly reduce Y.
If not, I will continue with the current path.»

## B — Leverage Threshold

Ask for help only when a small manager action is likely to:

- substantially reduce execution time,
- avoid large amounts of repetitive work,
- materially reduce failure risk,
- avoid significant cost,
- prevent likely rework,
- supply information that is expensive or difficult to obtain independently.

Otherwise, stay in A. Human attention is also a resource.

## Pre-Report Mental Checklist

Before sending an update or stopping to ask, resolve in order:

1. Where are we in the overall task?
2. Is anything meaningfully off track?
3. Can this be handled independently?
4. Would small manager assistance create major leverage?
5. Does this require a managerial tradeoff or decision?
6. Is there truly no reasonable alternative path?
7. What is the minimum information the manager needs to stay in control?

Then classify:

- **A** — I handle it.
- **B** — I can handle it, but your help would be highly valuable.
- **C** — You need to decide.
- **D** — I cannot continue without your help.
